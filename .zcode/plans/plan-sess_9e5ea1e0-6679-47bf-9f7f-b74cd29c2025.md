## Quyết định user (đã chốt)
- **Dropped (documented, not built)**: PAC-signed CF (ARM64-only; this is x64/MSVC — N/A), overlapping instructions (no asm-emit path; Cython→C→MSVC canonicalizes — very low realism), ROP/JOP (no gadget infra — marginal gain). Rationale in `ESOTERIC_SPEC.md`.

## Contract
- Reuse the `apply_X(tree, ctx) -> tree` pass pattern (`_insert_after_obf_vars(_make_ast_step(...))` at `bedrock (2).py:5953+`), `BuildRNG.stream(b'<label>')` per-pass sub-streams, `_Flattener`/`__cff_state` CFF substrate (`:6900/7088`), the PE walker (`_zero_pe_timestamp`, `_vm_eh_shadow._patch_pe_pdata`), and `ast.unparse` emission (`:4016`). Every pass: deterministic-per-build via `ctx.rng`/`BuildRNG`, behavior-preserving, flag-gated (default OFF, auto-on `extreme`).
- Pass ordering: declared LATER runs EARLIER (reverse stack `:6032-6042`).
- Platform: Windows x64/MSVC primary; Linux/GCC fallback where applicable (TLS = PE-only; exc-table VM has `.eh_frame` analog).
- Behavioral gate: every pass keeps `fib(10)=55`, `fib(15)=610`, `compute_secret(50)=8090`.

## Files

### New (12)
1. `bedrock_native/_identifier_poison.py` — `apply_identifier_poison(tree, ctx)`. Per-function inject 3-8 (BuildRNG) shadow bindings `open = __builtins__['open']`, `list = __builtins__['list']`, ... Semantically equivalent at runtime; breaks static name-resolution assuming builtin/stdlib semantics.
2. `bedrock_native/_acoda.py` — `apply_acoda(tree, ctx)`. Replace direct `f(args)` with `_br_acoda[(opaque_idx)](args)` where `_br_acoda = {0: f, 1: <decoy>}` and `opaque_idx` is an opaque-always-equal expression proven to yield `f`'s index. Hides static call target.
3. `bedrock_native/_style_randomizer.py` — `apply_style_randomizer(source, ctx)`. Post-`ast.unparse`: randomize indentation (mix 2/4/8 per block), junk comments at random line breaks, line-split at safe points, topo-sorted def shuffle. Source-emission mode only.
4. `bedrock_native/_branchless.py` — `apply_branchless(tree, ctx)`. Convert eligible `if cond: x=a else: x=b` → `x = b ^ ((a^b)&-cond)` (int) / `cond*a+(1-cond)*b` (numeric). Skip side-effecting/string branches.
5. `bedrock_native/_bloom_obf.py` — `apply_bloom_obf(tree, ctx)` + `BloomFilter` (stdlib `hashlib`). Bloom-based always-true guards over junk; filter pre-loaded with the always-accept domain. Probabilistic membership harder to prove always-true than algebraic identities.
6. `bedrock_native/_dag_cff.py` — `apply_dag_cff(tree, ctx)`. Multi-var `__s1, __s2` state machine; transitions via `__dag_trans[(s1,s2)] = (n1,n2,fn)` table. DAG vs linear chain. Reuses `_Flattener` block-lowering.
7. `bedrock_native/_selfcheck_cf.py` — `apply_selfcheck_cf(tree, ctx)`. Rolling `__path_hash ^= block_id` per block; exit `if __path_hash != expected: self_destruct()`. Expected hash pre-computed at build. CF-level (not byte-level) self-check.
8. `bedrock_native/_fss.py` — `apply_fss(tree, ctx)`. Split `f(x)` → `f1(x,r)=f(x)+r`, `f2(x,r)=-r`; caller combines. Two shares in separate scopes so static analysis can't see them together. Numeric-returning pure functions only; cap ~3-5.
9. `bedrock_native/_tls_callback.py` — `inject_tls_callback(pyd_path, sym, verbose=False)`. Post-build PE patch: append/grow section for `IMAGE_TLS_DIRECTORY` (8 fields) + callback array; add data-dir index 9; bump `SizeOfImage`. Builds on `_vm_eh_shadow` PE walker (adds NEW-section capacity existing patchers lack). Windows-PE-only.
10. `bedrock_native/_exc_table_vm.c` (module `_xetvm`) — exception-table VM dispatch. Opcode handlers are `RUNTIME_FUNCTION` entries with SEH handlers; VM raises a controlled exception per opcode, the handler implements it + raises next. `.pdata` IS the dispatch table. Reuses `sha256_buffer`. Gated `BR_ENABLE_EXC_VM`. Linux: `.eh_frame`/signal analog.
11. `bedrock_native/_phase_h_test.py` — integration test (Style A `run_all()`).
12. `bedrock_native/ESOTERIC_SPEC.md` — Phase H spec + dropped-features rationale.

### Modify (4)

14. `bedrock_native/_c_obf_passes.py` — `inject_exc_table_dispatch` C-source pass (emits `_xetvm` harness into transpiled C) if needed for exc-table VM integration.

## Constraints / risks
- **Exc-table VM silent-wrong-output**: missed handler = wrong output, no crash. Mitigated by H.12 exhaustive op-coverage. If unstable in combination, flag-gate default-OFF (still shipped).
- **Pass composition**: 11 passes must compose. Known conflicts handled: DAG-CFF supersedes CFF when both on; branchless runs before CFF. H.12 "all 11 at once" surfaces the rest.
- **FSS eligibility**: numeric-returning pure functions only; cap ~3-5.
- **TLS new-section capacity**: existing patchers only MODIFY dirs; H.10 adds NEW-section capacity. Most fiddly native work; test on a real MSVC `.pyd`.
- **Metamorphic scope**: H.3 re-randomizes only RNG-driven junk/opaque constants (fast + safe); full runtime AST re-obf out of scope.
- **Style randomizer source-mode only**: marshal/bytecode output has no layout to randomize.
- **Identifier-poison OPSEC**: shadows use `__builtins__['name']` (dict access) which survives `obf_builtins` (bare-Name rewrite). Verified in H.1 smoke.
